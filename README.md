# ⚛️ Curso de React — Do Zero ao Avançado

## 📚 Descrição

Bem-vindo ao treinamento intensivo em **React**, desenvolvido para levar o aluno do nível iniciante ao avançado!

Neste curso, serão apresentados os principais fundamentos do React e, posteriormente, conceitos avançados por meio de exercícios e projetos práticos.

O objetivo é preparar o aluno para desenvolver aplicações modernas, integrando **Front-end, Back-end, APIs, bancos de dados e autenticação**.

---

## 🚀 Conteúdos do Curso

Durante o treinamento serão abordados:

- ⚛️ React do básico ao avançado
- ⚡ Vite
- JSX
- Componentização
- 🎨 CSS e estilização
- 📝 Formulários
- 🌐 Requisições HTTP
- 🔄 Context API
- JavaScript ES6+
- 🔌 APIs externas
- 🟢 Node.js
- 🚂 Express
- 🍃 MongoDB
- Mongoose
- 🔐 Autenticação de usuários
- 🗄️ Integração com bancos de dados
- 💻 Desenvolvimento de aplicações completas
- 🧪 Exercícios práticos
- 🚀 Projetos práticos
